# SinoTalk (سينوتوك) — V2 Snapshot
Professional Arabic–Chinese Translation Platform (Web PWA, Windows `.exe`, Android `.apk`)
- 2,663+ verified HSK/CC-CEDICT Chinese characters (offline IndexedDB)
- Natural HD Mandarin/Arabic Voice Engine (`voiceEngine.ts`)
- Animated Step-by-Step Hanzi Stroke Order + Practice Quiz (`hanzi-writer`)
- Trade & Travel Phrasebook + Chinese RMB Price Converter + HSK Flashcards
- Client-side PDF & Word (`DOCX`) parser + Tesseract.js Camera/Image OCR
- 100% Free & Open-Source, Zero Accounts, Zero Tracking.

## Quick Start
```bash
npm install
node scripts/build_full_hsk_dictionary.js
node scripts/generate_png_icons.js
npm run build
npm run build:exe
```
